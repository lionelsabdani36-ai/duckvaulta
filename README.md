## 🚀 Key Modules

### 1. Corporate Portal (`apps/portal`)
* **Design Philosophy:** Strict adherence to Anti-Slop UI standards (zero generic purple glow, high contrast WCAG AA, zero em dashes, authentic responsive grid).
* **Interactivity:** Custom Anime.js timelines, live telemetry diagnostic visualizers, and spatial SVG radar components.

### 2. EdTech AI Platform (`apps/edtech`)
* **Core Value:** *"Ubah 6 Jam Belajar Jadi 1 Jam dengan AI"*, inspired by Pelajarin.ai.
* **Study Modules:**
  * **Auto-Summarizer:** Document, slide, and lecture compression into core conceptual points.
  * **Smart Flashcards:** Interactive spaced repetition cards for long-term memory retention.
  * **Multiple-Choice Quizzes:** Instant question generation with real-time answer validation and explanations.
  * **24/7 AI Tutor:** Patient conversational simulator for challenging formulas and concepts.
* **Dual Authentication System:**
  * **Student Workspace:** Daily streak tracking, XP points, saved study decks, and document uploads.
  * **Admin Command Console:** Real-time user metrics, document analytics, AI inference telemetry, and revenue monitoring.
* **Digital Monetization Engine:** 4-tier SaaS pricing (Freemium, Siswa Pro, Pejuang Ujian, and Guru/Bimbel).

### 3. Autonomous AI Team (`agents/`)
Powered by Hermes Agent profiles operating under coordinated Kanban task boards and Cron automation:
1. **Leader (Agent Nyawit):** System orchestrator and technical lead.
2. **Trend Hunter:** Market intelligence and digital business opportunity scout.
3. **Fullstack Dev:** Web platform architect and component engineer.
4. **QA Engineer:** End-to-end regression tester and accessibility auditor.
5. **Security Engineer:** Zero-trust defense, TLS auditing, and session isolation specialist.

## 🛡️ Security & Privacy
* Production environments use ECDSA Let's Encrypt TLS certificates with HTTP/2 and HSTS preload headers.
* All credentials, API keys, and Discord gateway tokens are strictly isolated and redacted.
* Internal inference endpoints (Ollama, 9router) are bound strictly to `127.0.0.1` and accessed only via authenticated gateways.
