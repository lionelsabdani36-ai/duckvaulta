CHALLENGE #18 : WEB EXPLOITATION (TRI-LAYER AUDIT)

Insp3ct0r : Client-Side Source Audit

Tantangan audit kode peramban web dasar. Sebuah portal modern dibangun dari tiga pilar web standar: HTML (struktur markup), CSS (tata letak visual), dan JavaScript (logika interaksi klien). Periksa ketiga berkas sumber tersebut untuk mengumpulkan ketiga potongan flag kompetisi.

ANALISIS & SILABUS LKS
  • Potongan ke-1 tersimpan di dalam komentar berkas HTML (gunakan View Source atau Developer Tools Elements).
  • Potongan ke-2 tersimpan di dalam komentar berkas lembar gaya CSS (style.css).
  • Potongan ke-3 tersimpan di dalam komentar berkas skrip klien JavaScript (script.js).
  • Gabungkan ketiga potongan berurutan membentuk flag lengkap CTF{...}, lalu submit via tombol di Discord!
