WPA-ing Out (ID 237 · Forensics · Medium)

Misi: password WiFi bocor lewat udara. Bob pakai password yang sama dengan salah satu entri rockyou.txt. Retas handshake WPA dari file pcap, temukan password, format jadi flag.

File: wpa-ing_out.pcap (1 MB, 802.11)

Langkah resmi

aircrack-ng wpa-ing_out.pcap -w /usr/share/wordlists/rockyou.txt
# atau: hashcat -m 22000 hash.hc22000 rockyou.txt
# flag = CTF{password_ditemukan} (format komunitas; native academy{...} juga diterima bot)

Petunjuk: buka di Wireshark untuk lihat beacon + 4-way handshake (EAPOL). SSID + BSSID ada di beacon frame.

Tanpa cracking? (Edukasi pola)

tshark -r wpa-ing_out.pcap -Y "wlan.fc.type_subtype==0x08" -T fields -e wlan.ssid | sort -u
tshark -r wpa-ing_out.pcap -Y eapol | wc -l   # pastikan handshake lengkap (>=4 pesan)
