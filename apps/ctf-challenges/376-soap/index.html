ANALISIS & SILABUS LKS
  • Kerentanan XML External Entity (XXE) terjadi ketika parser XML backend mengevaluasi deklarasi DOCTYPE dan ENTITY SYSTEM eksternal.
  • Contoh payload referensi entitas sistem: <!DOCTYPE foo [ <!ENTITY xxe SYSTEM "file:///etc/passwd"> ]> lalu panggil &xxe; di dalam tag nilai data.
