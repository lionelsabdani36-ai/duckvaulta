CHALLENGE #4 : WEB EXPLOITATION (RECON / ROBOTS.TXT)

where are the robots

Bisakah kamu menemukan halaman rahasia yang disembunyikan pemilik situs dari mesin perayap (web crawlers / search engine bots)? Periksa protokol standar yang digunakan pengembang web untuk mengatur akses bot.

ANALISIS & SILABUS LKS
  • Berkas robots.txt diletakkan di root web untuk menginstruksikan bot mesin pencari mengenai direktori apa saja yang tidak boleh diindeks (Disallow:).
  • Periksa robots.txt pada direktori tantangan ini untuk melihat direktori yang sengaja disembunyikan.
  • Flag resmi berformat CTF{...}. Submit jawabanmu via tombol di Discord!
