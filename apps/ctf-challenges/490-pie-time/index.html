PIE TIME (ID 490 · Binary Exploitation · Medium)

Misi: program mencetak alamat main() lalu meminta alamat lompatan. Hitung alamat win() dari offset dan lompat ke sana untuk cetak flag.

Proteksi PIE mengacak base address tiap run — tapi offset win - main selalu sama. Bocoran alamat main = kunci.

File asli: vuln.c · vuln (ELF 64-bit)

Cara main: download vuln + vuln.c, analisis offset win-main via objdump, jalankan ./vuln di mesinmu, hitung target = main_bocor + offset, masukkan → You won! + flag. Flag yang keluar dari biner itulah flag resmi — submit via 🚩 Submit Flag di Discord.

Simulasi di bawah ini cuma buat latihan hitung offset. Menang di simulasi ≠ dapat flag. Flag HANYA keluar dari biner asli.

Simulasi interaktif

Address of main: 0x55a3f2c1e1a9 Enter the address to jump to, ex => 0x12345: _

Petunjuk: offset = win - main. Cari dengan objdump -d vuln | grep -A2 '<main>\|<win>' lalu hitung selisihnya.

Cara analisis lokal

objdump -d vuln | grep -E "<(main|win)>:"
# misal main=0x11da win=0x126d -> offset = win - main = 0x93
# target = alamat_main_bocor + offset
chmod +x vuln
(echo 0xtarget; cat) | ./vuln
