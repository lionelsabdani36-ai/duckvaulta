Cryptography

RSA: Manual Solver

Masukkan parameter yang diketahui (n, e, c, p, q, d, atau phi). Kosongkan yang tidak ada.

Serangan Khusus RSA

Wiener (small d), Common Modulus (dua ciphertext dengan n sama), dan Hastad Broadcast (e=3).

XOR, Affine, Caesar, Vigenère, Railfence

Diffie-Hellman Key Exchange

Hitung Shared Secret: K = B^a mod p = A^b mod p.

Elliptic Curve Point Math: y² = x³ + a·x + b (mod p)

Penjumlahan titik P + Q atau perkalian skalar k · P (Double-and-Add).

Hash Crack (Wordlist CTF Cepat)

Dictionary attack kilat di client-side untuk MD5, SHA1, SHA256 terhadap ribuan password umum.

Reverse Engineering

Decompile .pyc / .class / .jar + disassembly ELF (objdump), inversi algoritma & sequence XOR, gaya Dogbolt.

Upload .pyc (Python), .class/.jar (Java), atau ELF/PE (Linux/Windows). Analisa header, konstanta bytecode, serta string tersembunyi.

ELF & PE Header Inspector

Bongkar executable header: bitness (32/64-bit), endianness, CPU architecture, entrypoint address, dan section headers.

Python .pyc Bytecode Inspector

Identifikasi magic number versi Python (Python 2.7 hingga 3.13), PEP 552 timestamp/bitfield, dan ekstrak constant pool strings.

Algorithmic Transform & Inversion Reverser

Balikkan transformasi aritmatika/bitwise: ROL/ROR (1-7 bit), penambahan/pengurangan modulo 256, bitwise NOT, dan indexed XOR (i*A + B).

Sequence-Key XOR Reverser

XOR dekripsi menggunakan deret matematika deterministik: Bilangan Prima, Fibonacci, Lucas, Bilangan Segitiga, dan Bilangan Kuadrat.

Binary Exploitation

Helper pwn: cyclic pattern & offset, checksec, ROP gadget. Analisa lokal: tak menembak target.

Cyclic Pattern (De Bruijn Sequence)

Generate pola De Bruijn non-repeating untuk memicu crash buffer overflow dan temukan offset presisi register RSP/EIP.

Analisa ELF (Checksec Auditor)

Audit proteksi biner: Stack Canary, NX / DEP, PIE / ASLR, dan RELRO.

ROP Gadgets & Shellcode Library

Snippet shellcode umum x86/x64 Linux (/bin/sh) dan template script pwntools siap pakai.
