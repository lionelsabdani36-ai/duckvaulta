1. Panduan Command Admin OP (Operator Essentials)

Operator (OP) di Cycraft SMP terbagi ke dalam 4 tingkatan izin. Pastikan pemberian akses disesuaikan dengan tanggung jawab peran.

Tingkat Peran Kewenangan Utama
Level 1 Spawn Builder Bypass proteksi spawn untuk pembangunan lobi
Level 2 Game Master Gamemode, teleport, cuaca, waktu, dan pengoperasian Command Block
Level 3 Moderator Tindakan disipliner pemain (/kick, /ban, /pardon, /mute)
Level 4 Administrator Hak penuh sistem server (/stop, /reload, /whitelist, /save-all)

Prosedur Pemberian OP via Terminal Shell VPS

Jalankan perintah ini langsung dari terminal host tanpa harus membuka layar console secara interaktif:

screen -S cycraft -X stuff "op WhiteJack^M"
screen -S cycraft -X stuff "op .WhiteJack^M"
Penting untuk Pemain Bedrock (HP): Sistem Floodgate menyematkan tanda titik (.) di depan nama pemain Bedrock. Saat memberikan OP ke pemain Bedrock, wajib menyertakan titik tersebut (contoh: op .WhiteJack).

2. Panduan Navigasi & Warp Antar World (Multiverse-Core)

Cycraft SMP menggunakan arsitektur multi-world untuk mengisolasi area lobi cyber hub dari area bertahan hidup (survival).

Nama Dunia Tipe Peruntukan
cyber_hub Flat World Lobi utama server, papan informasi, dan arena registrasi quest
world Normal Overworld Dunia survival terbuka untuk penjelajahan dan pengumpulan sumber daya
world_nether Nether Dimensi nether, eksplorasi benteng, dan stage tantangan tingkat lanjut
world_the_end The End Dimensi akhir untuk tantangan puncak (Ender Dragon & Elytra)

Perintah Navigasi Multiverse-Core (/mv)

/mv list
/mv tp cyber_hub
/mv tp world
/mv setspawn

Daftar Warp Resmi Server untuk Seluruh Pemain

Pemain biasa dapat berpindah antar lokasi tanpa perlu menghafal nama dunia dengan perintah warp sederhana:

  • /warp hub : Menuju titik pusat Cyber Hub lobi utama
  • /warp quest : Menuju area papan tantangan dan podium lomba
  • /warp survival : Menuju titik awal penjelajahan dunia survival
Status Konfigurasi: Hak akses essentials.warp, essentials.warps.*, dan multiverse.access.* telah dikonfigurasi aktif pada grup default melalui LuckPerms.

3. Panduan Setup Hologram Interaktif (DecentHolograms)

DecentHolograms digunakan untuk menyajikan teks informatif melayang dengan dukungan format warna, placeholder nama pemain, dan aksi klik interaktif.

Perintah Operasional DecentHolograms (/dh)

/dh h create hub_welcome &b&lCYCRAFT SMP
/dh line add hub_welcome 1 &7Selamat Datang di Server!
/dh click add hub_welcome LEFT [PLAYER] warp survival
/dh reload

Template YAML Hologram Siap Pakai

File konfigurasi disimpan di /home/lionelsabdani36/minecraft-server/plugins/DecentHolograms/holograms/:

name: cyber_hub_welcome
location: cyber_hub:0.5:-57.0:0.5
enabled: true
display-range: 48
update-interval: 20

- lines:
  - content: '&b&l⚡ CYCRAFT SMP ⚡'
  - content: '&7&oOfficial Crossplay Java & Bedrock'
  - content: '&e====================================='
  - content: '&fSelamat Datang di &b&lCyber Hub&r&f!'
  - content: '&a▶ &fKetik &a/warp survival &funtuk Dunia Survival'
    actions:
      LEFT:
      - '[PLAYER] warp survival'
  - content: '&b▶ &fKetik &b/warp quest &funtuk Area Quest & Arena'

4. Panduan Desain Quest & Arena Kompetisi (LKS / CTF)

Kurikulum kompetisi dirancang dengan metode Scaffolded Mastery (bertahap dari fondasi hingga analisis tingkat tinggi) oleh Master Guru Judith.

3 Tingkat Tantangan Akademik & Siber

  1. Tier 1 : Reconnaissance & Navigasi Presisi
    Peserta ditantang membaca koordinat 3D $(X, Y, Z)$ dan menemukan beacon tersembunyi untuk mengambil token bukti awal.
  2. Tier 2 : Gerbang Logika Hardware (Redstone Logic Gates)
    Peserta harus menyusun atau memecahkan kombinasi tuas biner yang memenuhi persamaan logika boolean (AND, OR, XOR) untuk membuka pintu besi brankas.
  3. Tier 3 : Kriptografi & Cyber Defense Flag Hunt (LKS Standard)
    Peserta memecahkan ciphertext (Base64 atau sandi substitusi) di dalam buku catatan rahasia di dimensi Nether untuk menemukan flag kompetisi: Purpur_CTF{...}.

Mekanisme Pembagian Hadiah & Scoreboard

  • Kit Pemula: Pemain dapat mengetik /kit starter untuk memperoleh Pedang Akademik, Beliung Logika, dan bekal dasar.
  • Kit Hadiah Quest: Pemenang tantangan dapat diklaimkan paket /kit quest_reward (5 Diamond, 10 Emerald, 2 Golden Apple, dan siaran pengumuman juara).
  • Sistem Skor Layar Kanan (Sidebar): 
    /scoreboard objectives add QuestPoint dummy "§e§lPoin Prestasi"
/scoreboard objectives setdisplay sidebar QuestPoint
/scoreboard players add WhiteJack QuestPoint 100

Proteksi Arena dari Kerusakan (WorldGuard)

Agar arena lomba tidak dirusak atau diganggu ledakan monster, lindungi wilayah dengan flag keamanan:

/rg define arena_quest
/rg flag arena_quest block-break deny
/rg flag arena_quest creeper-explosion deny
/rg flag arena_quest pvp deny
