Panduan Bergabung Berdasarkan Perangkat

  1. Buka game Minecraft Bedrock di Android, iOS, atau Windows.
  2. Tekan menu Play (Mainkan), lalu klik tab Servers.
  3. Gulir ke bagian paling bawah dan klik Add Server (Tambah Server).
  4. Masukkan data:
    • Server Name: Cycraft SMP
    • Server Address: 34.135.45.195
    • Port: 19132
  5. Tekan Save atau langsung Play.
Catatan Floodgate: Anda tidak memerlukan akun Java Edition. Sistem akan otomatis memberikan awalan tanda titik (.) pada nickname Bedrock Anda di dalam server untuk mencegah konflik nama.
  1. Buka Minecraft Java Edition (versi 1.16 sampai 1.21.4).
  2. Pilih menu Multiplayer lalu klik Add Server.
  3. Masukkan data:
    • Server Name: Cycraft SMP
    • Server Address: 34.135.45.195
  4. Klik Done, pilih server Cycraft SMP, lalu klik Join Server.
Catatan Akun: Server mengizinkan akun Java Original maupun launcher non-original (offline) karena didukung bridging Floodgate.

Panduan Operator (OP Admin)

Pemberian hak akses operator server dapat dilakukan melalui terminal console VPS atau RCON:

  • Memberikan OP Pemain PC (Java):
    screen -S minecraft -X stuff "op NamaPemain^M"
  • Memberikan OP Pemain HP (Bedrock):
    screen -S minecraft -X stuff "op .NamaPemain^M" (wajib sertakan titik di depan)
  • Mencabut Hak OP:
    screen -S minecraft -X stuff "deop NamaPemain^M"
  • Port RCON: 25575 | Password terdaftar di server.properties
